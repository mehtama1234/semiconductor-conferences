XSearch: what reading the full source showed

The official description identifies multi-fidelity Bayesian exploration and calibration across simulators, applied to XiangShan. It reports no numerical outcomes or evaluated baselines. The existing coding's single-fidelity comparator labels are researcher-inferred comparison ideas, not experiments documented by this source.

This is a useful mechanism example for fidelity-aware search, not evidence that the method beats a particular optimizer. Simulator identities, search objective, parameter ranges, calibration errors and total evaluation budgets are unknown.

Final-design feasibility and held-out high-fidelity evaluation matter more than the number of cheap design points explored. Simulator calibration also does not establish silicon accuracy.

Recorded searches recovered no exact manuscript or implementation. Overlapping authors on BigPower do not make that different work a substitute. Using an open-source processor is not evidence that XSearch itself has been released.

The structured assessment preserves the original coding and clarifies its interpretation. Independent review remains pending; absent numbers must not be treated as zero improvement.

Written as dac/reports/xsearch-primary-recovery-v1.md in the course repository.
