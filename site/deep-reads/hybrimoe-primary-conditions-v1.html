The version-pinned author preprint matches the program title and all six authors. Its implementation and experimental sections resolve conditions missing from the official description.

The structured extraction records section anchors, hardware, models, datasets, cache ratios, metric definitions and remaining unknowns. The raw HTML is locally captured with a recorded SHA-256.

The two headline averages compare against kTransformers, not every baseline (the existing method a new result is compared against). Only one concrete CPU (the general-purpose processor that runs ordinary programs)/GPU (a chip with thousands of small arithmetic units, first built for graphics) configuration is identified; cache-ratio variation must not be described as testing multiple physical platforms.

No independent execution or accuracy comparison was performed here. The malformed HTML ablation table and figure values were not transcribed.

This is supplementary evidence, not a replacement for the source-tier-matched description pilot. Obtain equivalent Icarus full-paper conditions before drawing a deeper cross-year comparison.
