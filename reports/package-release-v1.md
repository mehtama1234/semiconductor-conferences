# Dated intelligence package release — v1

Release date: 2026-09-07. Status: **bounded evidence assessment with scientific
gates still open**.

## What this release contains

- Complete paper-level routing for 1,589 inventory records across DAC, ISCA, and
  ICCAD, including the explicit ICCAD 2025 fallback for the unavailable 2026
  paper corpus.
- 582 technically coded records: DAC 544, ISCA 17, ICCAD 21, including one exact-title artifact-level BusyBarn record.
- 31 supplementary source-bound assessments and 23 dated recovery-attempt papers.
- An evidence-derived ten-theme taxonomy, mechanism-level synthesis, and explicit
  counterpressure/hypothesis reports.
- 582 review packets and a reviewer handoff protocol; no independent verdicts are
  represented as completed.
- Three newly recorded conditioned metrics (capacitance extraction, GAIA latency,
  and COPA overflow) remain explicitly withheld from headline synthesis until
  setup, baseline, workload, and holdout conditions are recovered.
- A bounded BusyBarn artifact reproduction matrix: normal AllGather (`80`), normal
  AllToAll (`208`), single-node-fault AllGather (`76`), and single-node-fault
  AllToAll (`252`) under one pinned synthetic configuration. These are artifact
  simulation outputs, not paper-level performance claims or independent review.
- A deterministic 582-packet reviewer-assignment manifest with two placeholder
  reviewer slots per packet and zero synthesized verdicts.
- Temporal pilot comparisons and title-shift routing signals, all bounded by an
  explicit insufficient-evidence finding for directional claims.
- A 118-artifact reproducibility manifest and a passing validation/test suite.
- A remediation record showing all 582 packets pass deterministic source/provenance preflight; independent review remains pending.
- A five-record P1 condition-extraction batch with source locators, evaluation
  conditions, and unresolved boundaries for high-risk quantitative claims.
- A second five-record P1 extraction batch covering ADC testing, edge LLMs,
  multi-die FPGA DSE, technology co-optimization, and asymmetric tile buffering.
- A third five-record P1 batch covering MoE serving, quantum synthesis, RTL
  benchmarking, glass-storage scheduling, and wafer-scale artifact conditions.
- A fourth five-record P1 batch covering concurrent PIM scheduling, ECC
  coordination, speculative decoding, PuD interference, and agentic inference.
- A fifth P1 recovery batch that records explicit missing-condition requirements
  for five DAC records whose full sources remain unavailable.
- A sixth P1 recovery batch covering six repository- and abstract-backed records
  with explicit conditions still required before quantitative use.
- A first P2 routing tranche prioritizing ten DAC description-only records for
  manuscript/abstract/artifact recovery.
- A second P2 routing tranche prioritizing ten additional DAC mechanisms across
  compiler, verification, security, memory, quantization, and serving.

## What users may conclude

The package supports a provenance-aware capability map: the selected papers show
cross-layer mechanisms involving data movement, tool-grounded design loops,
representation-aware acceleration, reliability/security constraints, and
verification-aware evaluation. It does not support venue-wide prevalence,
commercial adoption, or rising/declining trend claims.
