# Dated intelligence package release — v1

Release date: 2026-09-07. Status: **bounded evidence assessment with scientific
gates still open**.

## What this release contains

- Complete paper-level routing for 1,589 inventory records across DAC, ISCA, and
  ICCAD, including the explicit ICCAD 2025 fallback for the unavailable 2026
  paper corpus.
- 581 technically coded records: DAC 544, ISCA 16, ICCAD 21.
- 31 supplementary source-bound assessments and 23 dated recovery-attempt papers.
- An evidence-derived ten-theme taxonomy, mechanism-level synthesis, and explicit
  counterpressure/hypothesis reports.
- 581 review packets and a reviewer handoff protocol; no independent verdicts are
  represented as completed.
- Three newly recorded conditioned metrics (capacitance extraction, GAIA latency,
  and COPA overflow) remain explicitly withheld from headline synthesis until
  setup, baseline, workload, and holdout conditions are recovered.
- A deterministic 581-packet reviewer-assignment manifest with two placeholder
  reviewer slots per packet and zero synthesized verdicts.
- Temporal pilot comparisons and title-shift routing signals, all bounded by an
  explicit insufficient-evidence finding for directional claims.
- A 117-artifact reproducibility manifest and a passing validation/test suite.
- A remediation queue for the 3 packets requiring source capture or field-level
  reconciliation before independent review.

## What users may conclude

The package supports a provenance-aware capability map: the selected papers show
cross-layer mechanisms involving data movement, tool-grounded design loops,
representation-aware acceleration, reliability/security constraints, and
verification-aware evaluation. It does not support venue-wide prevalence,
commercial adoption, or rising/declining trend claims.
