# HybriMoE: primary-condition supplement

The [version-pinned author preprint](https://arxiv.org/html/2504.05897v1)
matches the program title and all six authors. Its implementation and experimental
sections resolve conditions missing from the official description. The
[structured extraction](../data/hybrimoe-primary-conditions-v1.json) records
section anchors, hardware, models, datasets, cache ratios, metric definitions and
remaining unknowns. The raw HTML is locally captured with a recorded SHA-256.

The two headline averages compare against kTransformers, not every baseline.
Only one concrete CPU/GPU configuration is identified; cache-ratio variation must
not be described as testing multiple physical platforms. No independent execution
or accuracy comparison was performed here. The malformed HTML ablation table and
figure values were not transcribed.

This is supplementary evidence, not a replacement for the source-tier-matched
description pilot. Obtain equivalent Icarus full-paper conditions before drawing
a deeper cross-year comparison. Neither paper's existence establishes that
HybriMoE was attacked, or that a technical trend changed. Independent review and
final-proceedings version reconciliation remain pending.
